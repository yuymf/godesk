# Design

<!-- impeccable:design-schema 1 -->

## Surface

Web Studio and creator home. Operate mode. ChatCut-style prompt workspace.

## World

Sunday table. Cool bone-green canvas (`#e8f0eb`), white paper cards, ink (`#1c2622`).
One forest accent (`#0f6b4c`) owns primary actions and a thin rail edge — not a dark slab.
The Shared Session table uses the same daylight: paper header, forest actions,
bone-green canvas. Friends opening an invite do not drop into a navy slab or beige felt.

## Type

One CJK-first sans: PingFang SC / Hiragino Sans GB / Noto Sans SC / Segoe UI.
No Inter-as-display. No uppercase eyebrows on the default path.

## Hierarchy

Home: one composer dealt onto the table, then optional starters, then examples.
Studio: pending plan first, joinable play first once a Build exists, everything
else secondary. Validation and system facts stay collapsed.

## Motion

Focal: the composer is dealt onto the table (rise, slight rotate, shadow bloom).
Feedback: starter chips lock in, dropzones lift, ready CTA sheens.
Continuity: example cards stagger in as a dealt hand. Ambient daylight wash.
Honor `prefers-reduced-motion`.

## Anti-references

Dark charcoal studio. Mint-on-charcoal ChatCut clone. Beige luxury paper.
Navy play-room chrome. Brass gold CTAs. Validation cockpit as the home screen.
"生成 Rule System" as the primary CTA. Numbered 01-05 capability strips.
