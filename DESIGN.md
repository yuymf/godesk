# Design

<!-- impeccable:design-schema 1 -->

## Surface

Web Studio and creator home. Operate mode. ChatCut-style prompt workspace.

## World

Dark charcoal workbench (`#0d0e10` / `#14171c`) with one mint accent (`#8ef0b7`).
The editor stays dark. The Shared Session table can keep its own play-surface
material, because play is the output, not another settings panel.

## Type

One UI sans: Inter / system stack. No display serif on Operate surfaces.
Headings carry their own weight. No uppercase eyebrows on the default path.

## Hierarchy

Home: one composer, then optional starters, then existing examples.
Studio: pending plan first, joinable play first once a Build exists, everything
else secondary. Validation and system facts stay collapsed.

## Motion

State only. 140-250ms. Honor `prefers-reduced-motion`.

## Anti-references

Validation cockpit as the home screen. "生成 Rule System" as the primary CTA.
Numbered 01-05 capability strips. Cream Generation Plan island inside the dark
studio.
