# GoDesk Codex Plugin

This is the public, thin Codex Plugin distribution for
[GoDesk](https://godesk.yumengfan220.workers.dev).

It contains only:

- the Codex Marketplace manifest;
- GoDesk Plugin metadata and brand assets;
- creator workflow Skills;
- the declaration for GoDesk's hosted MCP endpoint.

Game projects, rules, builds, rooms, replays, authentication, and deterministic
execution remain on the hosted GoDesk service.

## Install

Give Codex Desktop this sentence:

> 阅读 https://godesk.yumengfan220.workers.dev/chatgpt-plugin，帮我安装 GoDesk；完成登录与功能验证后，自动新建一个 Codex 任务，开始制作我的第一个桌游。

The hosted page is the authoritative, version-specific installation contract.
