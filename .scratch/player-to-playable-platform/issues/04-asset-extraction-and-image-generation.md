# Asset extraction and image generation

Type: task
Status: ready-for-agent
Blocked by: 02

## Question

Can supplied boards and components be extracted into usable game assets, with
missing visuals generated automatically and provenance kept explicit?

## Acceptance

- Boards, cards, tokens, and shared artwork are segmented and mapped to
  components.
- Low-quality or missing visuals enter a generation task automatically.
- Generated images are editable or replaceable and labeled by provenance.
- The runtime uses the resulting asset manifest without hard-coded Manila paths.
