# Rule understanding and game compiler

Type: task
Status: ready-for-agent
Blocked by: 02

## Question

Can the platform convert uploaded rules into a source-linked game definition and
ask only the minimum high-impact clarification?

## Acceptance

- Setup, components, actions, turn order, constraints, settlement, and game end
  compile into a versioned definition.
- Confidence and contradictions are evaluated automatically.
- Only unresolved high-impact ambiguity interrupts the player.
- Generated behavior retains source anchors and deterministic scenario tests.
