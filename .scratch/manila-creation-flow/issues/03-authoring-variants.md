# Compare authoring workflow shapes

Type: prototype
Status: resolved
Blocked by: 02

## Question

Which interface shape best exposes sources, AI candidates, human decisions, and
runtime consequences?

## Answer

Three same-route variants now answer different subquestions: a four-column
workbench for comparison, a provenance graph for broken-link diagnosis, and a
guided flow for focused confirmation. A human usability session must choose the
winner.
