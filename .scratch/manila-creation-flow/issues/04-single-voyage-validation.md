# Source-linked single-voyage validation

Type: prototype
Status: resolved
Blocked by: 02

## Question

Can reviewed facts drive an authentic three-player phase inspector while keeping
missing rule coverage visible?

## Answer

Implementation covers harbor-master auction, selecting three of four goods,
start-position validation, four
placements, three movements, pirate timing, pilot timing, and settlement as an
eleven-stage inspector. Loans, full insurance settlement, blind passengers, and
complete victory remain explicitly unimplemented. Browser QA covered all three
authoring variants, the dry-run surface, constraint behavior, desktop layout,
390 px layout, and browser logs.
