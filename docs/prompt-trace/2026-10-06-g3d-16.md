4. **开局路径**：`copyExample("tidewell-isles")` → `createSharedSession(..., { aiSeats: [1] })`，满足「2 次点击进可玩 Room」。
5. **叠分支**：不碰 main 直至 #138 合入；本 PR base 指向 `feat/g3d-13-tidewell` 以保持 diff 干净。
