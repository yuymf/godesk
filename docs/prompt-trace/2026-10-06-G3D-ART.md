## decisions

- 生成器输出一律 1280x720：贴图取中心 720² → 1024 → **逐轴 offset-by-half + 噪声扰动羽化混合**做无缝（先 x 后 y，接缝落在权重 1 的中心线上），2×2 平铺校验图存证据目录。
- normal / ORM 不另外生图：由无缝 albedo 亮度高度场推导（wrap 高斯 + 中心差分；AO = 腔体项，粗糙度≈常量）。这样三张图严格对齐，体积也小。
- 预算：自定更紧的 150 KB@512 / 50 KB@256（SPEC 220 / 70），normal 用 UASTC RDO 4.0（超限降 ETC1S q）。
- `t11-parchment` 只被 number-token 用 → 直接换成 N1 筹码面（圆外以边缘色填充防 mip 渗色），3D 筹码立即生效，零代码改动。
- `t07-cliff / t09-paintwood / t10-canvas` 无对应 AI 图，保留 CC0。T7 海面图不用（海面为 G3D-08 自研 shader）。
- `t08-wood` 原图青灰会被 wood token 暖棕乘暗 → 后处理去饱和 0.25、提亮 1.55。
- HUD 面板框重建为干净 9-slice（四角原角花 + 素边条 + 纸色中心；去掉会被拉伸的中饰与原图内部残影）；卡框保留中饰，slice 取大值，适用约 3:4。
- AI 资产 manifest `status` 仍为 `cleared`（运行时 `isRenderAssetCleared` 才会用），另加 `legalReview: "pending-G3D-17"` 作为发布闸门；LICENSES 仍 11 列，`法务审查:` 标记写在修改说明列，`verify-assets` 校验标记齐全（缺 → error）并汇总 warning。
- 不做：HUD 接线（图标 / 9-slice 框 / UI 筹码面放 `assets/ui/ai/`，留给 G3D-13）；3D 模型网格仍为 bpy 自制。
