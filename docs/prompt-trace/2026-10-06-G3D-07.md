## decisions

- **单一 token 源。** `src/render3d/tokens.ts` 的 `SCENE_TOKENS` 照抄 §3.7：AgX、曝光 1、太阳方位 135° / 仰角 52° / 强度 2.6 / `#fff4e0`、半球 `#dfe9f5` / `#b59c74` / 0.7、阴影半径 4、bias −0.0004、normalBias 0.02、环境光 0.35、天空渐变色。单测断言它与 creator `defaultRenderSpec` 的 lighting 一致，避免两套数值漂移。镜头参数只写在 tokens 里，不在本刀应用（镜头归 G3D-09）。
- **阴影随档位缩放。** 阴影贴图尺寸沿用 G3D-06 的档位上限（high 2048 / medium 1024 / low 512）。PCF 半径：low 固定 1；其余为 `1 + softness × 6`，默认 softness 0.5 时为 4。阴影相机按岛屿包围盒自动收紧（外扩 1.5 格）。`shadowMap.autoUpdate = false`，只在内容、档位或 PBR 贴图变化后的 1.5 秒内逐帧重绘，静止时不再重绘阴影。
- **PBR 随档位缩放。** high / medium 用 512 贴图，low 用 256；high 的棋子用 `MeshPhysicalMaterial`（清漆 0.3），medium / low 用 `MeshStandardMaterial`。PBR 贴图在可交互后 1.2 秒开始一套一套地流式加载，先用纯色 + 世界坐标噪声图案兜底，所以首帧和首屏体积不受影响。`?pbr=0` 可关闭。
- **环境反射只给光滑材质。** 直接设 `scene.environment` 会把 high 档的地块阴影冲淡，所以 RoomEnvironment 的 PMREM 只挂到粗糙度 ≤ 0.6 的材质（棋子、清漆木），地块仍只吃太阳与半球光。
- **座位颜色不被 PBR 改色。** 座位棋子用 paintwood（t09）的法线 / ORM，不用它的 baseColor（`pbrBaseColor: false`），玩家颜色保持可辨。地形材质的 baseColor 贴图向白色混合 0.55，再乘上地形色，保证六种地形一眼可分。
- **修 KTX2 transcoder 路径。** `loaders.ts` 默认 `basisPath` 原为 `/basis/`，但这个目录从未部署，KTX2 一直加载失败（G3D-22 时没有调用方，所以没暴露）。r186 的 KTX2Loader 在 `basisPath` 为空时会用 Vite 打包后带哈希的 transcoder（`import.meta.url`），因此改为空字符串。e2e 断言没有失败的 ktx2 / basis 请求，并且 wasm 确实被取到。
- **降档重建不重复下载贴图。** SwiftShader 上 perf:ci 冷启动会 high → medium → low 运行时降档；medium → low 要关 MSAA，只能重建 SceneHost，重建后又按 256 下载一遍，首局请求数达到 80 / 80（预算上限）。改为：KTX2 字节在页面内跨挂载缓存（`fetch` + `KTX2Loader.parse`，每次传副本，因为 buffer 会转移给 worker）；low 要 256 时，若同一套 512 已经下载过就直接复用。perf:ci 首局请求数 80 → 51，首局字节 3.26 MB → 2.68 MB。复用发生时容器带 `data-pbr-reused`。
- **泄漏门按同档位比较。** high 档多一张 PMREM 环境贴图，降档后的挂载因此比首次挂载少 1 张贴图，`leak.memoryDriftAfter10Remounts` 误报 1。`memoryOnMount` 记录每次挂载的档位，漂移改为与「同档位的第一次挂载」比较，说明里列出各次挂载档位（本地：high,low×11）。卸载残留检查不变。
- **CSS tokens。** `design-tokens.css` 按 §3.7 增加 `--surface-canvas` / `--surface-paper` / `--surface-raised`（#ffffff）/ `--surface-board`、`--shadow-soft` / `--shadow-card` / `--shadow-float`、`--hud-glass` / `--hud-glass-blur`。旧的 `--surface-raised` 实际是 #f5f5f5 的凹陷底色，全部 45 处引用改名为 `--surface-sunken`，填充色不变（charter e2e 对 `.action-log` 的 rgb(245,245,245) 断言保持成立）。`--canvas` / `--paper` 仍为白色，首页与房间底色本刀不改；`--surface-paper` 按 §3.7 改为 #fbf8f1 后，房间头部（`.room-shell-header`）、创作台侧栏等随之变为纸色，charter e2e 的「浅色游玩面」断言把头部期望从白改为 rgb(251,248,241)，房间底色与 `.action-log` 断言不变。gallery e2e 的 token 断言把 token 与期望值都挂到探针元素上比较解析值，因为生产构建会把 `0.10` 压成 `.1`。首页的标题胶囊、输入框、示例作品卡改用阴影 tokens。DESIGN.md 的「不加浮动卡片阴影」改为「阴影只能来自 `--shadow-*` tokens」。
- **§9 LCP / TBT。** 按劳埃德的决定：继续只告警，G3D-17 优化后改阻断。
- 已知未达标、明确不在本刀修：medium ≤ 100、low ≤ 60 的 draw call 预算。G3D-07 之前三档每帧都是 140，已经超标；本刀把稳态降到 82，但阴影重绘期间的峰值为 145（high / medium）/ 126（low）。实例化 / 合批与 G3D-13 换 GLB 一起做。
