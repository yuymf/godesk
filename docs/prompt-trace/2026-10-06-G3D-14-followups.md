## decisions

- **实例化放在对象层，不改 mapper 输出。** SceneModel 仍是一子一节点（id 稳定，便于 diff / 动效）；`tabletop-objects.ts` 把 `disc` 节点建成不渲染的代理 `Object3D`，挂到父节点时加入该父节点上「每种材质一个」的 `InstancedMesh`，移除时退出；空批次移除并释放。翻子（换座位材质）= 代理从一个批次移到另一个。父节点 `updateMatrixWorld` 时同步代理矩阵到实例矩阵。批次容量 64（满了翻倍），`DynamicDrawUsage`，`frustumCulled = false`（实例分布在整个盘面，包围盒按单子算会被误剔），`raycast` 空实现（拾取走格子热点，不变），圆子扁平不投影（与 G3D-14 口径一致）。
- **draw call 单测口径。** jsdom 没有 WebGL，单测按渲染器实际提交估算：天空穹顶 1 + 可见网格（`InstancedMesh` 记 1）+ 投影网格（阴影 pass 再记一次），对照 `TIER_CAPS` 断言满盘 low ≤ 60、medium ≤ 100；另测中盘带提示、翻子 / 移除时批次增减。浏览器实测见 outcomes。
- **2D 棋子色。** `OthelloBoard.tsx` 把 `render.materials.seat0/1.base` 写成 CSS 变量 `--othello-seat0/1`，`surface.css` 的色块与圆子径向渐变读变量、缺省回退原黑白。不加新依赖，不碰 Kernel。
- **溢出根因。** `.othello-grid` 是 content-box，`width: 100%` 再加 12 px 内边距与 1 px 边框，在 390 px 视口下右缘 391。改 `box-sizing: border-box`。
- **毡面噪点判为产品问题。** t10-canvas 的 KTX2 只有 1 级 mip（levelCount 1）；桌面盒体 UV 按面归一、repeat 0.5，粗布纹被放大成约 2 px 的硬边块，太阳压到 18° 时法线起伏更显。同一局 `?pbr=0`（程序化布面）平滑，所以不是 SwiftShader 采样问题。本刀从 `PATTERN_PBR` 去掉 `cloth → t10-canvas`，毡面保留程序化布面；带 mip 重烘 KTX2（`toktx --genmipmap`）属 Track B（G3D-22），box 上没有 toktx，本刀不做。
- **证据脚本入库、截图不入库。** `scripts/g3d-14-followups-evidence.mjs`：生成「做一款两人翻转棋」，两个浏览器上下文各占一席下到终局（满盘），按 low / medium 截桌面 1440×900 与 iPhone 12 Pro 的舞台 / HUD / 整页，读 `?perf=1` draw call、`scrollWidth` 与溢出元素、2D 色块颜色；再走 MCP `configure_render`（与 G3D-15 第二刀同一组 patch）编译开新局截 `recolored` 与 `recolored-pbr-off`。before 用 main（`98f5de0`）构建，after 用本分支构建。
- **不做。** 不改 worker room / bot，不改水体 shader，不重烘 KTX2。
