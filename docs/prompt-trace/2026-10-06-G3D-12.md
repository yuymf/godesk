```ts
const hex = z.string().regex(/^#[0-9a-f]{6}$/i);
const unit = z.number().min(0).max(1);
const assetId = z.string().regex(/^[a-z0-9-]+\/[a-z0-9-]+$/); // must exist in the asset manifest with license cleared
export const materialSchema = z.strictObject({
  base: hex, roughness: unit, metalness: unit,
  clearcoat: unit.optional(),            // high tier only (MeshPhysicalMaterial)
  pattern: z.enum(["none", "grain", "cloth", "stone", "grass", "sand"]),
  texture: assetId.optional(),           // KTX2 texture from the manifest
});
export const renderSpecSchema = z.strictObject({
  version: z.literal(1),
  engine: z.literal("three-webgl2"),
  preset: z.enum(["tabletop-day", "tabletop-dusk", "parchment-map"]),
  camera: z.strictObject({ mode: z.enum(["orbit", "fixed"]), fovDeg: z.number().min(25).max(55), distance: z.number().min(6).max(40), minPolarDeg: z.number().min(10).max(80), maxPolarDeg: z.number().min(20).max(85), pan: z.boolean() }),
  lighting: z.strictObject({
    sun: z.strictObject({ azimuthDeg: z.number().min(0).max(360), elevationDeg: z.number().min(15).max(80), intensity: z.number().min(0).max(6), color: hex }),
    hemisphere: z.strictObject({ sky: hex, ground: hex, intensity: z.number().min(0).max(3) }),
    shadow: z.strictObject({ enabled: z.boolean(), softness: unit }),
    exposure: z.number().min(0.5).max(2),
  }),
  water: z.strictObject({ enabled: z.boolean(), shallow: hex, deep: hex, waveHeight: z.number().min(0).max(0.2), waveSpeed: z.number().min(0).max(2), foam: unit }),
  materials: z.record(z.string().regex(/^[a-z][a-z0-9-]{0,31}$/), materialSchema).refine((m) => Object.keys(m).length <= 32),
  bindings: z.array(z.strictObject({
    objectKind: z.string().min(1).max(40),   // GameSpec.objects[].kind, a region marker, or a Kernel node type
    mesh: z.union([z.enum(["hex-prism", "tile-square", "house", "tower", "road-bar", "pawn", "disc", "card", "die", "ship"]), assetId]),
    material: z.string(),                    // key of materials
    scale: z.number().min(0.25).max(4),
  })).max(48),
  motion: z.strictObject({ placeMs: z.number().int().min(120).max(600), moveMs: z.number().int().min(160).max(900), cameraMs: z.number().int().min(200).max(1200), diceMs: z.number().int().min(400).max(1400), easing: z.enum(["out-cubic", "out-back", "in-out-sine"]) }),
  audio: z.strictObject({
    master: unit, sfx: unit, music: unit,
    cues: z.partialRecord(z.enum(["hover","select","illegal","panel","toggle","place","upgrade","road","move","steal","dice","gain","trade","turn","win","lose"]),
      z.strictObject({ assets: z.array(assetId).min(1).max(6), gainDb: z.number().min(-24).max(0) })),
    ambience: z.array(assetId).max(2),
    musicTracks: z.array(assetId).max(3),
  }),
});
export type RenderSpec = z.infer<typeof renderSpecSchema>;
```

## decisions

- **迁移策略＝读时惰性迁移，单一入口。** `migrateRuleSystemToV2`（`src/creator/game-spec.ts`）是唯一理解 v1 的函数：纯函数、幂等；删除旧 `presentation.theme`；空间体裁（table / scene / hybrid）缺 render 时补 Kernel 默认；已存 `schemaVersion: 1` 的 GameSpec **原地升版**（补投影 render），不重新生成，因此陈旧 / 损坏的 v1 规格依旧 fail-closed；`schemaVersion` 为其它值（含未知未来版本）原样保留。Worker `normalizedRuleSystem` 对每次项目 / 构建读取调用它，Durable Object 在下一次写入时持久化。生产数据无需批处理任务，也无需额外凭据。
- **`theme` 删除，由 `render.preset` 取代。** MCP `ruleSystemSchema.presentation` 保持非 strict，旧客户端发送的 `theme` 被剥离而非拒绝；`update_rule_system` 省略 `render` 时保留当前声明，不会被清空；非法 render（未知材质、未登记许可证资产、俯仰角区间无效、schema 不符）返回 `invalid_rule_system`，存储不变。
- **默认 render 只用几何体原语，不引用资产 id。** 资产许可证登记表 `render-asset-registry.ts` 暂为空 Map，G3D-11（Track B）的 manifest 在此接入；本刀**不**创建 `src/render3d/assets/manifest.ts`。
- **未改动的平台默认跟随 Kernel，作者改过的 render 永不覆盖。** `isUntouchedDefaultRender` 以当前默认 token 的规范化字符串判定；G3D-15 若调整默认 token，需同步考虑旧默认的识别。
