## decisions

- 新模块 `src/render3d/motion.ts`：`MOTION_MS`、`prefersReducedMotion`、`MotionController`（单个 tween `Group`，由 SceneHost 渲染循环 `update`）、`precomputeDiceTumble`（mulberry32 确定性曲线，终帧精确落在点数朝向）、`arcLift`。
- `reconcile.ts` 增加可选 `motion` 钩子（added / updated / removed）；**首次 reconcile 不播动画**；注册表立即反映新状态，淡出中的对象打 `userData.removing` 且 `pick.ts` 跳过，避免点到已不存在的节点。
- 输入不丢失：拾取走 hit overlay（同步按合法动作重建），tween 不加锁；同一对象上新 tween 先 `end()` 旧 tween，最终姿态总收敛到权威状态。
- 骰子：状态无掷骰计数，`lastAction` 转入 `roll_dice` 视为一次掷骰（处理与上次相同点数 / 初始 [1,1] 静止位，e2e 首掷 1+1 暴露此问题）。
- 回合镜头：`activeSeat` 变化 → 相机目标回岛心；建造 / 强盗 / 掷骰 → 目标朝事件位置拉近 35%；OrbitControls `start/end` 记录拖拽，3 s 内不自动移动。
- 不做：键盘平移（SPEC 明确不做）、物理引擎、GLB 骰子模型（G3D-13 / G3D-21 素材集成时替换几何，不影响曲线）。
- e2e 观测：`window.__g3dMotionLog`（≤200 条，`{kind,id,durationMs,reduced}`）。
