## decisions

- **mapper 纯函数、三层拆分。** `mappers/tabletop.ts`（不引用 three）：`TabletopLayout`（底板 + 可选规则网格、格位、棋子、连线、合法提示）+ RenderSpec → `SceneModel`、材质表（库 key 带材质值摘要，`configure_render` 改材质后 key 变化、对象换材质）、节点 → 动作表、网格落点换算。`mappers/tabletop-kernels.ts`：四个 Kernel 的公开状态 → 布局（桌面约 8 单位宽；线路坐标归一；工人区按 √n 列排格位、按容量排工人位；港口 3 条航道 0–13 + 港口格、货船带货色圆片、码头 / 船厂 / 特殊格位）。`tabletop-objects.ts`：内置网格工厂（tile-square / disc / pawn（Lathe 单网格）/ house / tower / road-bar / card / die / ship / hex-prism / 提示环 / 网格线）。找不到 binding 时按 objectKind 回退内置图元。
- **渲染宿主只加最小接口。** `SceneHost` 新增可选 `scene`（`SceneAdapter`：model / create / update / resolvePick / bounds / layoutKey / camera）。有适配器时：不走 hex mapper、不放测试立方体、不建 hex 热点叠加层；reconcile `model`；布局变化时阴影相机按包围球重算；机位按 RenderSpec.camera（fov、极角取 min/max 中点、距离按包围半径缩放，窄屏时再拉远到水平放得下，pan 开关、极角限制）；棋子新增走 `place` 动效、位置变化走 `moveArc`。hex 路径行为不变（perf:ci 全部 PASS，hex draw call 141）。
- **render3d 核心预算。** 通用 mapper、适配层与网格工厂只被 creator 侧懒加载的 `TabletopScene3D` 引用，打进 `TabletopScene3D-*.js`（5.3 KB gzip，`check-size-budgets` 新增 ≤ 12 KB 一行），不计入核心。SceneHost 被 hex 盘与通用桌面共享后成为无 facade 的共享 chunk，Vite 原规则会把它命名为 `index-*` 并误计入首页预算；`chunkFileNames` 改为按内容判定（只含 `src/render3d`、three、tween 的 chunk 归 `render3d-`）。核心 205.70 → 206.88 / 210 KB（SceneHost 适配器 + three 多出的 Lathe / Ring / Extrude / LineSegments）。
- **首页预算。** 首页只多一个静态外壳 `TabletopStage`（懒加载 + 固定高度占位）。第一版懒加载 chunk 引用了 `defaultRenderSpec`：`render-spec.ts` 在首页 chunk 内，被懒加载 chunk 引用的导出不能再被摇掉，首页因此 +1.1 KB（size-limit 超 193 B）。改为：棋盘组件把 `build.ruleSystem.presentation.render` 透传给舞台；旧 build 缺 render 时由懒加载 chunk 内的最小兜底（tokens 灯光 + 座位色 + 内置图元回退）。首页 165.04 → 165.22 KB；size-limit 168.68 → 168.88 / 170 kB。
- **DOM 动作盘保留。** 四个棋盘组件在 HUD 下方挂 3D 舞台，原 DOM 盘 / 动作按钮保留在下方作为可访问动作列表（e2e 与无 WebGL 设备照常可玩）。3D 拾取与 DOM 按钮发同一 actionId / payload；只读（预览 / 回放 / 非自己回合）时不传 `onAct`，3D 不发动作。
- **拾取。** 提示环、格位、货船直接查动作表；翻转棋底板按命中点换算格子。网格线 `LineSegments` 关闭射线检测：Line 的射线阈值（1 单位）会抢在底板前命中，而命中点不在盘面上，导致第一版 3D 点击落空（e2e 抓到）。
- **材质。** pattern → G3D-22 套件（grain → t08、cloth → t10、stone → t07、grass → t03、sand → t06）。作者写的底色必须原样可辨（`configure_render` 改色要看得见），所以只借套件的法线 / ORM（`pbrBaseColor: false`），木桌 `table` 例外；座位材质借 t09 彩漆木的法线 / ORM。翻转棋默认 render 的 seat0 / seat1 改为黑 #1d1d1f / 白 #f4efe6（棋子必须黑白分明）。
- **水面。** 开启 `water` 的 Kernel（港口）桌面换成一片水面色平面（`water.shallow`），不是 G3D-08 的水体 shader，未碰 Track B 范围；G3D-15 第二刀的改水色一轮因此在通用桌面上可见。
- **draw call。** 扁平件（圆片 / 卡牌 / 格位 / 底板 / 提示环 / 网格线）不投影，阴影重绘帧几乎不加 draw call。medium 实测稳态 / 峰值：翻转棋 9 / 9（5 子）、线路 19 / 29、工人 8 / 10、港口 48 / 51；翻转棋满盘上界约 64 子 + 3 + 提示 ≈ 70–80，medium ≤ 100 达标；low ≤ 60 在翻转棋后盘（> 55 子）会超，实例化留给后续。
- **不在本刀。** 区域名 3D 文字（DOM 盘已有）；工人 / 港口的座位色沿用 RenderSpec seat0–3（与 DOM 盘的商会色不同，按 SPEC「座位色只来自 materials seat0–seat3」）。
