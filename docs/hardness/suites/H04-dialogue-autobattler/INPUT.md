# H04 多轮对话脚本 — 从零自走棋（非潮汐名）

每行一轮；第 1 轮走 `/chatgpt-plugin/new`，其后 Studio 迭代。

1. 做一款两人自走棋，商店买棋上阵自动打架，熔岩灰烬风格，名字叫灰烬佣兵团
2. 初始血量改成30，初始金币改成10
3. 每回合商店和布阵各限时25秒，超时自动开打
4. 加一个新单位「矿工」，费用1，攻击45，生命650，羁绊岩石，外形像龟
5. 加一个新单位「火法」，费用2，攻击70，生命480，羁绊岩浆，外形像精灵
6. 加一个新单位「盾卫」，费用1，攻击40，生命720，羁绊岩石
7. 加一个新单位「游侠」，费用2，攻击62，生命450，羁绊暗影
8. 新增羁绊「岩浆」，档位2和4，开战护盾20和45
9. 新增羁绊「岩石」，档位2和4，反伤0和0.1
10. 新增羁绊「暗影」，档位2和3，额外打击
11. 三个相同的棋子合成二星，属性变强
12. 加一个电脑对手，我一个人也能玩
