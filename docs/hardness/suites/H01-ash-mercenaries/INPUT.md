# 灰烬佣兵团 — 完整规则书

## 1. 概述

- **题材**：奇幻佣兵自走棋（非潮汐、非赛博机甲）。
- **人数**：2 人（我方 vs 对手；可与电脑对战）。
- **核心循环**：商店购买佣兵 → 备战席整理 → 上场布阵 → 锁定 → 自动战斗 → 结算扣血 → 下一回合。
- **产品称呼**：灰烬佣兵团；我方席「余烬营地」；对手席「黑岩佣兵」。

## 2. 开局设置

| 项 | 值 |
| --- | --- |
| 初始生命 | 30 |
| 初始金币 | 10 |
| 棋盘 | 7 列 × 2 行（己方半场）；对手镜像 |
| 备战席 | 5 格 |
| 商店刷新 | 每回合提供 5 张可选佣兵卡 |

## 3. 回合循环

1. **商店阶段**（25 秒）：花费金币购买；可刷新商店（费用按内核默认）；未花完金币可保留。
2. **布阵阶段**（25 秒）：从备战席拖到己方半场；可召回、出售。
3. **锁定**：双方准备完毕或超时后进入战斗。
4. **自动战斗**：双方单位按攻击与生命结算；羁绊效果在开战时/首击时按预设触发。
5. **结算**：败方扣血（规则与现有 auto-battler 伤害公式一致即可）；生命 ≤ 0 淘汰。

超时必须由服务端推进，无人操作时也应开打。

## 4. 胜负

- 一方生命降至 0 或以下 → 该方战败，对局结束。
- 显示终局文案（胜/负），禁止血量长期显示无意义负数而不结束（底线：终局时 HP 地板为 0）。

## 5. 升星

- **二星**：场上+备战席合计 3 个同名一星 → 自动合成 1 个二星；属性 ×1.8。
- **三星**：默认关闭；若开启则为 3 个二星合成，倍率另定。
- 本规则书默认：二星开启，三星关闭。
