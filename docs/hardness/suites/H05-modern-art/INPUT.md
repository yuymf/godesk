# 画廊竞拍 — 规则书（自写 · 现代艺术式拍卖）

> 自写硬度输入：多拍卖方式 + 画家行情结算卖出，**非**官方原文。

## 1. 概述
- 题材：当代画廊拍卖与炒作（非自走棋）。
- 人数：3–5 理想；可 2 人近似。
- 核心：每人持有不同画家的画作手牌；轮流作为拍卖官打出一张并选择拍卖方式；拍得者付款；一轮中同一画家卖到第 N 张则该轮结束，按本轮出售件数给画家排行情，持有者可卖出得分。
- 产品称呼：画廊竞拍。

## 2. 开局
- 画家 4–5 位；每人发一把手牌（画作）。
- 资金若干（简化：每人 100）。
- 行情表初始为 0。

## 3. 拍卖方式（拍卖官指定其一）
1. **公开加价**：轮流出更高价，不过则落槌。
2. **一次暗标**：各写价格同时亮出，最高得（平手规则自定）。
3. **定价购买**：拍卖官标固定价，顺时针选择买或不买；无人买则拍卖官可自己买下或流拍。
4. **双画固定**：两张同画家一起定价（若手牌允许；否则 unsupported）。

## 4. 轮与行情
- 当某画家本轮第 3–5 张（按人数）被成功拍卖后，本轮结束。
- 按本轮各画家售出数量排序，更新行情价格阶梯；玩家可选择将手中该画家画作卖给银行换取行情价。
- 开始新一轮，手牌补充（简化可标）。

## 5. 胜负
- 固定轮数后资金+未卖画折算最高者胜。
- 禁止潮阵自走棋冒充。

## 6. 呈现
- 拍卖台 + 行情表 + 手牌；非战斗棋盘。
