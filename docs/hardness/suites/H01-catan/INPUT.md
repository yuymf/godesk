# 六角岛开拓 — 规则书（自写 · 卡坦式定居玩法）

> 本文为硬度测试用**自写**规则摘要，描述常见「骰点产资源 → 筑路定居 → 交易 → 强盗」核心循环，**不是**任何出版社官方规则原文。

## 1. 概述
- 题材：岛屿开拓与贸易（非自走棋、非拍卖行）。
- 人数：3–4 理想；管线可先按 2 人可执行内核近似。
- 核心：掷骰获得资源 → 用资源建造道路/定居点/城市 → 可与他人或港口交易 → 先到指定胜利点者胜。
- 产品称呼：六角岛开拓；我方「蓝湾开拓队」；对手「赤丘商团」。

## 2. 开局
- 标准六角岛盘：多种地形对应木材、砖块、羊毛、谷物、矿石；中央或指定格为沙漠（无产）。
- 每位玩家放置 2 个定居点与 2 段道路（交替放置）；定居点相邻地形在开局可拿起始资源（简化：各得 1 份相邻资源即可）。
- 每人 0 胜利点卡以外的起始分：每定居点 1 分。

## 3. 回合循环
1. **掷产**：主动玩家掷两枚六面骰；所有在对应数字顶点有定居点/城市的玩家按地形拿资源（城市产量加倍）。
2. **强盗**：若掷出 7，所有手牌≥7 的玩家弃一半；主动玩家移动强盗到一格地形，该格暂停产出，并可从一相邻对手处抽 1 张资源（若有）。
3. **交易**：可与他人议价交换资源，或按港口比率与银行换（通用港 3:1，专属港 2:1，简化：至少支持与银行 4:1）。
4. **建造**：支付费用建造——道路（木+砖）、定居点（木+砖+羊+谷）、城市（谷×2+矿×3，升级已有定居点）、发展卡（羊+谷+矿，若内核支持）。
5. **连通**：新定居点必须通过自有道路网到达；道路须从自有设施延伸。

## 4. 胜负
- 先达到 **10 胜利点**者立即获胜（定居点 1、城市 2；最长道路/最大军队等奖励分若内核无则标 unsupported）。
- 不得把本规则书做成商店买棋自动打架。

## 5. 内容清单（示意）
- 地形：林、丘、牧、田、山、漠。
- 资源：木、砖、羊、谷、矿。
- 港口：通用与专属（可简化）。

## 6. 呈现意图
- 六角岛 + 道路/定居点棋子；资源与骰点 HUD。
- 非潮阵棋盘、非机甲自走战斗。
