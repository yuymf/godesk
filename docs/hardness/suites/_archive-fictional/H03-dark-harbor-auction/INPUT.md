# 暗港拍卖 — 规则书

## 1. 概述
- 题材：暗港赃物拍卖（竞价），2–4 人。
- 核心：回合制密封/加价拍卖拍得赃物，再在黑市出售套利。
- 产品称呼：暗港拍卖；我方席「买家」；对手席「对手买家」。

## 2. 开局
- 每人资金 30；公共牌库 24 张赃物（名、底价、黑市倍率）。

## 3. 回合循环
1. 亮出 1 件拍品与底价。
2. 竞价：顺时针加价，或不加；连续全员过牌则落槌。
3. 结算：最高价者扣资金得物；无人叫价则流拍入弃牌。
4. 黑市阶段（可选）：出售手中赃物换资金（倍率按牌面）。

## 4. 胜负
- 牌库空后资金最高者胜。

## 5. 内容清单（摘录 8 件）
暗港罗盘、伪旗、锈蚀火炮、密账、毒酒、走私香料、假护照、沉船图。

## 6. 呈现意图
- 拍卖台 + 出价 HUD；不是棋盘式自走战斗界面。
