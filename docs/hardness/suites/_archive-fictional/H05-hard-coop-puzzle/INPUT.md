# 雾林协奏 — 合作解谜规则书（故意难 / 非已有内核）

## 1. 概述
- 题材：2 人合作解谜（非对抗自走棋、非拍卖、非物流）。
- 核心：两人分持「火把」与「绳索」视角，在同一雾林地图解机关；需要沟通（本地可共享屏幕）。

## 2. 开局
- 共享 5×5 雾林格子；每人可见不同掩码。
- 每人 3 点行动力 / 回合。

## 3. 回合循环
1. 同时秘密选择行动（移动/照明/拉绳/祈祷）。
2. 公开结算；机关状态同步。
3. 若两人同回合踩中配对符文 → 解锁一层雾。

## 4. 胜负
- 合作：8 回合内打开神殿门 = 双胜；否则双败。

## 5. 内容
- 符文 6 种、陷阱 3 种、一次性和解道具「回声笛」。

## 6. 呈现
- 分屏雾林；非潮阵棋盘。
- **期望**：解析层承认无 coop-puzzle 内核，Plan 不标 executable；禁止静默生成潮阵房间冒充通过。
