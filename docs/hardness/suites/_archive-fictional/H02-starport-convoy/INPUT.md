# 星港车队 — 规则书（物流路线题材）

## 1. 概述
- 题材：星际物流竞速（非自走棋、非潮汐棋盘、非赛博机甲战斗表）。
- 人数：2–4 理想；硬度基线要求管线识别为路线/物流网络类玩法，而非商店买棋自走战斗。
- 核心：玩家经营车队，在星港节点间派车运货，抢先完成合约。
- 产品称呼：星港车队；我方席「蓝港车队」；对手席「赤湾车队」。

## 2. 开局
- 每名玩家 1 艘起步货船、资金 20、信誉 0。
- 地图：6 个星港节点，部分边有通行费。

## 3. 回合循环
1. 市场：刷新 3 张货运合约（起点→终点、报酬、时限回合数）。
2. 调度：给船分配合约或停靠维修。
3. 航行：船沿边移动 1 步；经过收费边扣资金。
4. 交付：到达终点结算报酬与信誉。
5. 事件：随机空间风暴或海盗（可选，首版可标 unsupported）。

## 4. 胜负
- 先达到信誉 10，或资金破产（0 且无船）淘汰后最后存活者胜。

## 5. 内容清单
- 船型 4 种：驳船/快艇/武装商船/巨型矿驳（载重、速度、防护）。
- 合约类型 3 种：普通货、易碎、违禁（风险高报酬高）。

## 6. 呈现意图
- 星图节点 + 路线高亮；非棋盘式自走战斗 HUD。
