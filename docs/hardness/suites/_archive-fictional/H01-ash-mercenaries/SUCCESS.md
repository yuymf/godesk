# H01 成功标准

## 可玩闭环
- [ ] 新项目生成 → Plan 确认 → 房间或「和电脑对战」打开
- [ ] 至少完整 1 回合：买入（或电脑买入）→ 布阵 → 锁定 → 战斗结算，无崩溃

## 规则忠实度（claim vs observed）
- [ ] kernel = `auto-battler-v1`，`runtimeSupport.executable = true`
- [ ] 单位表含「矿工/火法/盾卫/游侠…」等灰烬名，**不是**礁蟹/海风灵或钻头机兵
- [ ] 羁绊含「岩浆/岩石/暗影」，**不是**潮汐/珊瑚咒或能源/装甲
- [ ] 计时商店/布阵约 25s（或迭代后写入的值）；初始 HP 30、金币 10（若首轮未写入，迭代轮须能写入）
- [ ] branding 标题含灰烬/佣兵语义，或 jobs 明确列出「未执行的品牌要求」（不得静默标潮阵）

## 呈现底线
- [ ] theme.preset = `ember`（因规则书含熔岩/灰烬 cue），或 presentationFloor 草稿条款写明未过闸原因
- [ ] 棋盘非空白；商店卡面文字可读

## 冷启动
- [ ] 全新 `--persist-to /tmp/wr-hardness-*` 重跑，上述层结论一致
