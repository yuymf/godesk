# 瓷砖工坊 — 规则书（自写 · 花砖物语式草稿）

> 自写硬度输入：工厂拿色 → 铺准备行 → 墙纹计分与地板扣分，**非**官方原文。

## 1. 概述
- 题材：瓷砖装饰竞赛（非自走棋、非拍卖）。
- 人数：2–4。
- 核心：从工厂展示或中心堆拿**同色**瓷砖，放入个人准备行；一轮结束后将满行的瓷砖贴到纹样墙得分，多余与未放置的掉入地板扣分。
- 产品称呼：瓷砖工坊。

## 2. 开局
- 若干工厂展示盘（人数相关），各随机 4 块瓷砖。
- 每人一块 5×5 纹样墙（每行每列颜色不重复的固定图案）与 5 条准备行（长度 1–5）及地板扣分格。
- 中心区初始为空，放「先手标记」。

## 3. 回合（草稿阶段）
- 轮流：选一个工厂，拿走其中**全部某一颜色**，其余推入中心；或从中心拿走某一颜色全部（若拿中心且先手标记在则一并拿走先手标记，本轮结束你下轮先手，但先手标记占地板一格）。
- 拿走的砖必须放入一条准备行：该行只能是这一颜色；放不满则留下，下一轮继续；放不下的掉地板。

## 4. 墙贴与计分
- 当无人可拿时进入墙贴：每条从左满的准备行，将 1 块贴到该行墙的对应颜色格，其余回收。
- 得分：新砖按正交相连已有砖计分；若无相邻则 1 分。
- 地板上的砖按格扣分（越往后扣越多）。
- 清空工厂再填，开始下一轮，直至有人墙上一整行满。

## 5. 胜负
- 有人完成至少一行后结束本轮结算，再加行/列/颜色套奖励；最高分胜。
- 禁止做成自动战斗。

## 6. 呈现
- 工厂圆盘 + 准备行 + 纹样墙；非潮阵 HUD。
