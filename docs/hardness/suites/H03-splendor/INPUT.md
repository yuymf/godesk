# 宝石作坊 — 规则书（自写 · 璀璨宝石式引擎）

> 自写硬度输入：宝石代币引擎 + 发展牌折扣 + 贵族，**非**官方原文。

## 1. 概述
- 题材：文艺复兴珠宝商竞争（非自走棋、非六角岛）。
- 人数：2–4。
- 核心：拿宝石代币 → 买发展牌获得永久宝石折扣与声望 → 满足贵族条件自动拜访；先到声望阈值者胜。
- 产品称呼：宝石作坊。

## 2. 开局
- 五种基本宝石 + 黄金万能（数量随人数变化，简化：各色堆充足即可）。
- 发展牌三层（1/2/3 级）各翻开 4 张；余牌成列。
- 贵族牌若干正面朝上（人数+1）。
- 每人声望 0、无永久折扣。

## 3. 回合行动（四选一）
1. 拿 3 枚不同色基本宝石；或拿 2 枚同色（该堆须足够多）。
2. 保留 1 张可见或牌库顶发展牌，并拿 1 黄金（手牌保留上限 3，简化可标）。
3. 支付宝石（可用永久折扣抵扣）购买 1 张发展牌，放入个人阵列，获得该牌颜色折扣与声望。
4. （若规则允许）仅整理，但标准局每回合一动。

贵族：若你的永久折扣满足某贵族需求，立即获得该贵族与其声望（无需行动）。

## 4. 胜负
- 任一玩家在自己回合结束时声望 ≥ **15** 则触发终局核对，最高声望胜（简化：先到 15 即胜亦可）。
- 禁止绑成潮阵自动战斗。

## 5. 内容
- 宝石色：白蓝绿红黑 + 金。
- 牌级：1 级低费低分，3 级高费高分。
- 贵族：需求为若干色永久折扣组合。

## 6. 呈现
- 三级牌列 + 代币堆 + 个人阵列；非棋盘自走战斗。
