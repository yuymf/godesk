# 洲际铁道 — 规则书（自写 · 车票之旅式铺线）

> 自写硬度输入：描述「抽车厢牌 → 认领彩色路线 → 完成车票起终点」核心，**非**官方规则原文。

## 1. 概述
- 题材：铁路竞速铺线（非自走棋、非六角产资源）。
- 人数：2–5 理想；可先 2 人内核。
- 核心：收集彩色车厢牌，支付对应颜色与长度认领地图上的路线；持有车票（城市 A→B），用自有路线连通则得分，未连通则扣分。
- 产品称呼：洲际铁道；席位「北线公司」「南线公司」。

## 2. 开局
- 公共地图：若干城市与彩色（或灰色任意色）路段，长度 1–6。
- 每人起始车厢指示物若干（简化：15–45 均可，内核按自身上限）。
- 每人抽车厢手牌；再抽 3 张车票，至少保留 1–2 张（简化：开局固定 2 张车票目标）。

## 3. 回合循环（三选一）
1. **抽车厢牌**：从公开 5 张脸朝上中拿，或盲抽；脸朝上的彩虹多功能牌有拿取限制（若内核无彩虹则 unsupported）。
2. **认领路线**：支付与路段颜色、长度匹配的车厢牌，放置自家车厢，得分按长度表（短低长高）。
3. **抽车票**：再抽车票，保留至少一张新票（简化：可标部分 unsupported）。

## 4. 胜负
- 车厢用尽触发最后一轮；结算：路线分 + 完成车票加分 − 未完成车票扣分；可选最长连续路奖励。
- 禁止做成自动战斗自走棋。

## 5. 内容
- 颜色：红橙黄绿蓝紫黑白及灰。
- 车票示例：港城↔矿山、都会↔边陲 等（用地图节点名即可）。

## 6. 呈现
- 城市图 + 已占路线着色；手牌/车票 HUD。非潮汐战斗盘。
